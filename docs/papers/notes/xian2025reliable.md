## Summary

The position paper that most directly argues the paper's premise from the organization-science side: coordination, control, delegation and accountability in LLM agent systems are the same balancing problems high-functioning human organizations face, and the evidence-based theories developed for organizations should inform agent design. It offers three organizational accounts for agent engineering, covering agency versus capability in design, resource constraints versus performance in scaling, and internal versus external mechanisms in management. Included as an older but central framing citation because the knowledge base already holds the computer-science-side counterpart (2607.25446) but nothing from this direction; note that the abstract does not name Sah-Stiglitz or Csaszar, so it complements rather than substitutes for the paper's formal theory base.
