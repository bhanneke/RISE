## Summary

270 tasks over 90 papers in computer science, social science and medicine at three difficulty levels, testing whether an agent can reproduce a study's results from the provided code and data, with a parallelised evaluation harness and both AutoGPT and a task-specific CORE-Agent baseline; best accuracy on the hardest level was 21%.
