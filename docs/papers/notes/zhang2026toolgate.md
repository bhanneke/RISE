## Summary

Addresses the acceptance problem in building scientific agent benchmarks: LLM-proposed items are kept only if an executable solution script reproduces the answer in the real scientific software, randomized no-tool screening rejects items solvable from the prompt alone, and a tool-using agent solves the survivor within a time budget. Instantiated in FEniCSx, 500 generation attempts yield 128 unique protocol survivors. Turns benchmark construction into an auditable process rather than expert hand-curation, which matters for the credibility of every tool-use research-agent benchmark.
