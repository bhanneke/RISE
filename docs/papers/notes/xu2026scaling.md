## Summary

Social-science (not ML) demonstration that an AI-assisted pipeline can retrieve materials, rebuild environments, execute code and match outputs to published regression-table point estimates at scale: 384 stratified studies from the top three political science journals (2010-2025), 3,523 empirical models replicated. Reproducibility rises from 20.8% pre-DA-RT to 82.5% after, and 92.1% conditional on an accessible replication package; the same infrastructure then supports systematic IV re-diagnostics across 597 specifications. The closest existing template for an IS/econ replication-agent argument.
