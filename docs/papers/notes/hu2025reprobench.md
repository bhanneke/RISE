## Summary

112 task instances built from social science papers that have public reproduction reports; agents receive the paper PDF plus the reproduction package and must judge reproducibility, not merely re-run code, which is what distinguishes it from result-reproduction benchmarks. Leading agents scored 21.4%; the authors' REPRO-Agent improved 71% over the best prior approach. OLDER than the window but flagged because it is the reference benchmark for social-science reproducibility assessment (and the target that PaperRepro, 2603.00058, and 2602.08561 are scored on), and the dedupe file shows no entry for it.
