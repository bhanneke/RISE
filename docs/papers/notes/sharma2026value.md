## Summary

Reframes AI-text detection away from surface style toward informational contribution: VOLM measures how much value a human added over a replacement-level document an LLM could produce from the task description alone, by reconstructing the document from progressively coarser content representations and comparing against task-description-only reconstructions. It needs no training or labels and never scores surface text, so it resists humanization and paraphrase. One of the three evaluation domains is ICLR peer reviews, making it a methodologically distinct approach to the detection-of-AI-reviews problem.
