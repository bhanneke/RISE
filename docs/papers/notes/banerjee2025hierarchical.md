## Summary

Addresses error attribution in LLM multi-agent systems - pinpointing which agent and which step caused a failure - and proposes ECHO, combining hierarchical context representation, objective analysis-based evaluation and consensus voting, reporting superior performance on subtle reasoning errors and complex interdependencies. A useful post-MAST citation for the measurement side of the paper: if failures can be attributed to specific agents and steps, traceability is measurable rather than rhetorical.
