## Summary

The strongest pro-hierarchy counterweight to the self-organization and diversity-collapse results: a three-layer company-style framework (governance, execution, compliance) that beats flat collaboration across reasoning tasks while cutting tokens, reporting a 102.73% performance gain with 74.52% fewer tokens for GPT-OSS-120B on SQuAD 2.0. It also states the conditions under which hierarchy pays - stable skill assignment, controlled information flow, layered verification - which is a usable set of moderators. Cite as evidence that organizational structure shapes effectiveness, cost and coordination behaviour simultaneously, and distinguish on outcome: it measures task accuracy and token cost, not exploration, justification soundness or traceability.
