## Summary

Tackles the problem of evaluating reasoning quality in multi-agent LLM systems on open-ended tasks with no reference answer, comparing token-level log-probability confidence proxies against rubric-based LLM-as-judge scores in a debate-based essay-scoring framework. Early-token confidence, within the first few generated tokens, is consistently the strongest predictor of reasoning quality, and there is a systematic asymmetry by agent role, with confidence tracking quality more closely for supportive reasoning than for adversarial critique. The role asymmetry matters directly for any design in which some agents are assigned critic roles.
