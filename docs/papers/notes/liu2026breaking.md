## Summary

Names and formalizes the Martingale Curse - standard multi-agent debate cannot improve belief correctness beyond majority voting because correlated errors drive convergence to erroneous consensus - and proves that only nonlinear aggregation can convert an informational asymmetry into submartingale drift toward truth. The mechanism is a peer-prediction step in which agents forecast peers' belief distributions, scored with strictly proper scoring rules, so truth-holders are identifiable because they anticipate the crowd's misconceptions. This supplies a rigorous impossibility-style baseline for the aggregation dimension: it tells the paper which aggregation rules cannot in principle beat voting, which sharpens the contrast between voting, debate and synthesis.
