## Summary

The one paper that explicitly marries Sah-Stiglitz screening theory to LLM committees: it models error dependence that can differ between good and bad cases via an exchangeable Gaussian copula, shows shared errors create a positive asymptotic error floor for majority voting, and shows dependence changes the approval threshold that minimizes expected loss - with the framework relating organizational form to cost asymmetry (costlier false acceptances push toward hierarchy, cheaper ones toward polyarchy). Estimated on 174,384 votes from 28 language models over four binary-screening benchmarks with odd-to-even-item out-of-sample validation, identity-line R-squared rises from 0.840 under independence to 0.967, and cost-sensitive thresholding cuts scaled loss 15.73% below majority rule. Outside the requested window but reported because it is the nearest theoretical antecedent to this paper's structure-times-aggregation argument and is absent from the knowledge base - leaving it uncited would expose a priority problem.
