## Summary

The closest existing analogue to the paper's core design move: it argues LLM multi-agent frameworks conflate three logically distinct concerns - who is on the team (organization), how members align (coordination), and which algorithm fuses their work (collaboration protocol) - and builds IMACS to make them orthogonal, independently swappable layers. It runs controlled comparisons where organizational assignments vary while the collaboration protocol is held fixed, structurally the same identification logic as crossing organizational structure with aggregation rule. It also reports the winning organizational placement flips across model families, so organizational design cannot be hard-coded but must be revalidated per model binding.
