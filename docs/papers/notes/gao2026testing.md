## Summary

Tests whether an agent occupying a structural role is substitutable, forming eight independent teams from one base model, letting each agent keep a private notebook over ten formation episodes, then swapping role-matched agents against a placebo that reproduces roster disruption without changing the occupant. Swaps cost little in task score but raise communication per unit of progress by 16 to 63 percent, and the swap penalty moves together with how far independently formed teams drift apart. Relevant because it shows structure has effects invisible to accuracy metrics but visible in coordination and process, which is precisely the paper's argument for measuring epistemic quality rather than benchmark accuracy.
