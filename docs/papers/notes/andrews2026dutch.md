## Summary

Evaluates the coherence rather than the accuracy of LLM probabilistic forecasts: forecasts are elicited over logically related events built from stock-return data, then linear programs compute the largest guaranteed Dutch-book profit an arbitrageur could extract against the model's own probabilities, used as a measure of incoherence. The procedure requires no outcome labels, so coherence is measurable on questions that have not resolved; incoherence rises with richer logical relationships among events, and irrelevant contextual detail can raise it by an order of magnitude. For a research-forecasting task where ground truth is mostly unresolved this is the most useful measurement instrument in the window - it turns justification soundness into a label-free, quantitative, economically interpretable quantity comparable across organizational architectures.
