## Summary

OpenAI's benchmark requiring agents to replicate 20 ICML 2024 Spotlight/Oral papers from scratch, with 8,316 individually gradable rubric tasks co-developed with the original authors plus a separate benchmark for validating the LLM judge. Best tested agent reached 21.0% and top ML PhDs still beat the models on a subset.
