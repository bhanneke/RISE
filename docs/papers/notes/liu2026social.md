## Summary

Asks whether an interacting population of LLM agents aggregates genuine knowledge or collapses into false consensus, and argues classical social-network belief-aggregation models overstate pooling because LLM agents attend to only part of what they are exposed to. Their SNLA framework models how much each agent actually influences others rather than how the network merely connects them, and proves that narrow attention causes herding with effective sample size bounded regardless of population size, while wide attention recovers wisdom-of-crowds behaviour only when the exposure graph is undirected and degree-regular. That undirected/degree-regular condition is a precise structural statement of when a polyarchy-like arrangement delivers crowd wisdom and when it does not.
