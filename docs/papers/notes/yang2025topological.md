## Summary

Position paper arguing the field should shift to topology-aware multi-agent systems that explicitly model and dynamically optimize how agents interact, decomposing a system into agents, communication links, and topology and linking these to adaptability, efficiency, robustness, and fairness. The field-level statement that structure is a first-class design variable rather than an implementation detail, which is the premise the paper's experiment operationalizes. It also flags evaluation difficulty in MAS, supporting the argument that benchmark accuracy alone is an inadequate outcome measure.
