## Summary

Argues that existing AI-scientist benchmarks are configured for reproduction (recovering a hidden target study's result) rather than discovery, and builds 40 blind tasks from 40 peer-reviewed studies across 10 domains that expose only a neutral objective and frozen data. A fixed LLM judge scores evidentiary maturity on six dimensions via 29 artifact-grounded items with no per-instance human grading. Four coding agents on one frozen base model cluster in a narrow 58.4-60.3/100 plateau with no reliable separation: competent execution and documentation, but missing controls, robustness, falsifiability and cross-dataset generalization - the bottleneck is scientific judgment, not coding.
