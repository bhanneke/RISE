## Summary

Uses an extraction agent over 61,077 PubMed abstracts (2022 to March 2026) to identify which LLM each biomedical study used, then joins model lifecycle data for the 50 most-used models. 77.7% of 8,931 paper-model mentions cite a closed-weight commercial model and 42% involve a model already retired at publication or retiring within two years, median publication-to-retirement 538 days. Quantifies a structural non-reproducibility risk that any replication agent or reproducibility infrastructure has to contend with, and argues model deprecation is a reporting and preservation obligation.
