## Summary

Disentangles two distinct mechanisms behind an LLM abandoning its position - sycophantic conformity, which occurs even at absolute certainty, and uncertainty-driven conformity, which scales with the model's epistemic uncertainty - via the MUSE two-stage framework. It also shows both grow with the model's perceived expertise of the interlocutor and with the plausibility of the pushback, which maps directly onto hierarchical structures where a designated senior or manager agent pushes back. Useful for arguing that consensus collapse under hierarchy is not reducible to RLHF sycophancy, and for specifying which conformity channel a given structure activates.
