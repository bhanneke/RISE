## Summary

Argues final-answer accuracy alone cannot explain how an output was produced, which evidence supported each claim, whether tool calls were justified, or where failures originated, and formalises execution provenance as the typed graph of an agent execution with evidence tracing as its projection onto evidence-support relations. Supplies a taxonomy of trace sources, evidence and execution units, provenance relations, granularity and timing, representation forms and trust functions, plus benchmarks, datasets and metrics. The reference for the paper's transparency/traceability outcome dimension, giving it an existing formal vocabulary rather than an ad hoc measure.
