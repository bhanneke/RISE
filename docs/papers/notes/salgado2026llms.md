## Summary

Argues that responsibly folding LLMs into qualitative workflows requires researchers to engage explicitly with technical parameters - context window limits, temperature and top-p, user and system prompt design, model system cards - and situates these inside the epistemological commitments of qualitative research (reflexivity, positionality, interpretive judgement). Notes that LLM opacity differs in kind from earlier NLP tools like topic models and lexicon sentiment analysers. A practical methods reference for the qualitative side of IS research pipelines.
