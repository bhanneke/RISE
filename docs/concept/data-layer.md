# The data layer

> *Stub — content to be developed in Phase 2.*

The data layer supplies the empirical material a RISE pipeline operates
on. Planned sections:

- **Source typology.** Raw vs. curated; primary vs. derived; structured
  vs. unstructured; public vs. proprietary.
- **Access patterns.** Direct APIs, scraping (sandboxed), data brokers,
  research-data repositories.
- **Provenance and citability.** Persistent identifiers, dataset cards,
  versioning.
- **Sandboxing concerns.** SSRF protection, allowlisting, prompt-injection
  mitigation when ingesting external content.
- **Catalogs and discovery.** How a pipeline finds datasets relevant to
  its task.
