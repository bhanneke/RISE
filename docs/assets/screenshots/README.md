# Screenshots for the Get-started section

This directory is the drop-zone for screenshots referenced from
`docs/getting-started/*.md`. The naming convention is one of:

| Filename | Page that uses it |
|---|---|
| `github-signup.png` | manuscript.md §1.1 |
| `github-new-repo.png` | manuscript.md §1.2 |
| `overleaf-new-project.png` | manuscript.md §1.4 |
| `overleaf-github-link.png` | manuscript.md §1.5 |
| `claude-version.png` | agent.md §2.2 |
| `claude-welcome.png` | agent.md §2.2 |
| `codex-signin.png` | agent.md §2.3 |
| `finder-papers-dir.png` | first-workflow.md §3.1 |
| `agent-note-permission.png` | first-workflow.md §3.3 |
| `agent-commit-preview.png` | first-workflow.md §3.5 |

When you add a screenshot, also remove the placeholder line in the
referencing page (the line that begins with `> *Drop screenshot at`
near each `> ![Screenshot placeholder:` block).

Suggested specs:
- PNG, ≤ 1600 px wide, < 400 KB
- Crop tight to the relevant UI element; do not include
  personal data (emails, repo URLs other than the example, etc.)
- Light theme preferred for consistency with the site palette
